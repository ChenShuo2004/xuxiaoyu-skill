# 项目决策模板

这是本Skill设计的实用模板，非徐霄羽本人或AMINO官方尽调表。按实际任务裁剪，不为填表而编造信息。

## 1. 判断卡

- 项目：
- 任务：谁，在什么场景，需要完成什么结果？
- 当前替代方案与成本：
- 初步结论：值得验证 / 需要重构 / 当前证据不支持 / 已有初步支持。
- 判断依据与信心边界：

| 技术与替代 |  |  |  |  |
| 网络与分发 |  |  |  |  |

状态采用“用户陈述 / 已核验证据 / 推断 / 未知”。已核验证据应带时间、样本或出处，不能只写“市场很大”。一项用户访谈能支持痛点线索，不能证明全市场愿意付费。

补充经营判断时，以实际数据估算单次交付收入减去模型、人工审核与服务成本。成本、收入缺失时列待测字段；不要凭空写毛利、市场份额或财务预测。

先复用现有工具完成验证，实验结果支持后再决定是否建设独立产品。收集数据前明确使用权、用户同意范围与保留方式；不要默认将客户内容用于训练。

## 6. 融资叙事或项目比较

融资叙事按：真实任务→现有方案不足→产品交付→采用证据→优势积累→下一里程碑及资金用途。缺失项显示需要补充的证据，不虚构投资人兴趣。

项目比较使用同一证据矩阵。区分“当前更可执行”与“已证明长期价值更高”；当核心数据不可比时给出条件排序与各自首个实验，不强行给总分。
